# K20-LIV — Lecture après coup (orchestrateur)

Écrite après le verdict, sans effet sur lui. Le verdict est celui de `verdict.json` : **éliminée**, sans réserve de protocole
(schéma conforme sur les 548 lignes du calcul, 0 anomalie sur les 7 autres, accord expérimentateur-vérificateur sur les 63 champs ;
l'ambiguïté signalée par l'expérimentateur sur a et A, étape 7, n'a pas joué : les deux rôles ont suivi la lettre, moyennes groupées).

## Ce que dit le verdict

- **Le contrôle positif passe.** Le consensus Livingston sous-réagit : pente regroupée 0,37 (borne basse à 90 % : 0,26), pente
  après une petite nouvelle 0,44. Un supplément nul n'est pas le silence d'un instrument muet.
- **Le supplément après une grande nouvelle est négatif** : c = −0,12, IC à 90 % [−0,35 ; +0,11]. La prédiction (+0,40) est
  exclue au seuil unilatéral de 5 %. Sans chacun des onze épisodes, c reste négatif (de −0,13 à −0,06) ; avec la pandémie
  −0,32 ; depuis 1985 −0,04.
- **Le plancher a été mesuré, pas supposé** : part du bruit d'échantillonnage dans la variance des révisions ν = 0,016 (calculée
  sur les réponses individuelles), biais mécanique 0,12, plancher 0,12. Contrairement à K20-ZE (plancher calculé avec ν = 0,20 :
  0,43), le plan avait ici une vraie chance de survivre si l'effet existait.

## Ce qu'il faut dire franchement

1. **Un écart à la simulation** : k moyen vaut 1,02 (cibles en niveau) et le rapport des variances de révision 10,1, loin des
   dispersions de K20 utilisées dans le scénario principal (0,29 et 3,1). C'est le scénario S-b (« sans doute le plus réaliste »),
   où la probabilité d'éliminer sous c = 0 n'était que de 0,78. Le contrôle positif a passé, et le verdict tombe.
2. **Par variable**, une seule a un c positif : le chômage, +0,38 (ET 0,29). Les autres sont négatives (IPC −0,22, taux
   préférentiel −0,44, bon du Trésor −0,03, mises en chantier −0,47). Dans l'enquête de la BCE aussi, le seul signe positif
   notable venait du chômage (avec les cibles 2020-2021). Une piste pour plus tard, sur une seule variable, après coup : pas un
   résultat.

## Ce qu'on retient pour le projet

Trois enquêtes (SPF américain, BCE, Livingston), deux continents, 1947-2026 : le consensus sous-réagit en moyenne (pente de 0,19
à 0,37) et cette sous-réaction **ne grandit pas** avec la taille des nouvelles (c de −0,12 à −0,03 ; la taille prédite, +0,40,
est exclue dans les deux tests concluants). L'hypothèse de la fiche (réticence aux grandes révisions) est rejetée.
