# K20-ZE — Lecture après coup (orchestrateur)

Écrite après le verdict, sans effet sur lui. Le verdict est celui de `verdict.json` : **éliminée**, sans réserve de protocole
(schéma conforme sur les 578 lignes du calcul, 0 anomalie ailleurs, accord expérimentateur-vérificateur sur les 65 champs).

## Ce que dit le verdict

- **L'instrument voit l'effet de base.** Le consensus de la BCE sous-réagit : pente commune 0,37 (borne basse à 90 % : 0,27) ;
  pente après une petite nouvelle 0,45. Le contrôle positif passe : un supplément nul n'est pas le silence d'un instrument muet
  (contrairement à K11).
- **Le supplément après une grande nouvelle est nul ou négatif** : c = −0,11, IC à 90 % [−0,26 ; +0,05]. La prédiction de la
  fiche (+0,40) est exclue au seuil unilatéral de 5 %. Sans chacun des trois épisodes, c reste négatif (de −0,19 à −0,06).
- Par variable : inflation +0,13 (ET 0,17), PIB −0,22 (0,16), chômage −0,15 (0,21). Aucune ne s'approche de 0,40.

## Trois choses à dire franchement

1. **Le plancher de survie a été bien plus haut que prévu.** La simulation de décisivité supposait un rapport des variances de
   révision d'environ 3 (calibré sur K20) et donc un plancher de 0,10. Le rapport observé vaut 8,4 et le biais mécanique calculé
   0,43 : sous la vraie prédiction (c = 0,40), le test aurait surtout fini « non concluant » (intervalle contenant à la fois le
   plancher et 0,40). La probabilité de 0,89 « sous H1 » était donc trop optimiste. **L'élimination n'en dépend pas** : elle vient
   de la borne haute (0,05 < 0,40), et le biais mécanique pousse c vers le haut, pas vers le bas. Une élimination est prudente.
2. **Avec la pandémie, le signe change.** L'analyse secondaire S3 (préinscrite, hors verdict) remet les cibles 2020-2021 du PIB et
   du chômage : c = +0,18 (ET 0,08). La préinscription les excluait avant de voir les données, parce qu'une poignée de cibles y
   pèse plus que deux décennies. Lecture prudente : hors du choc de 2020, rien ; dans le choc de 2020, un supplément positif mais
   encore loin de 0,40 (borne haute à 90 % ≈ 0,30). Une question pour plus tard, pas un résultat.
3. **L'ambiguïté des égalités** (`ecarts.md`, C1) : l'expérimentateur et le vérificateur ont suivi la même lettre (double
   précision, sans arrondi) ; l'autre lecture (arrondi) donne c = −0,099 et les mêmes conditions de règle. Le verdict ne dépend pas
   de cette lecture.

## Ce qu'on retient pour le projet

Dans la zone euro comme aux États-Unis (K20 : c = −0,03, [−0,15 ; +0,09]), le consensus sous-réagit en moyenne, et cette
sous-réaction **ne grandit pas** avec la taille des nouvelles. L'hypothèse de la fiche (réticence aux grandes révisions, H1)
est rejetée sur les deux enquêtes. Ce qui reste compatible : une rigidité de taille constante (H0, Coibion et Gorodnichenko 2012),
ou une attention qui monte un peu avec les chocs (H2 : c légèrement négatif dans les deux enquêtes, sans être significatif).
